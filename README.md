AMETHYST METEOR v2   (data pack - nothing to build)

INSTALL   put this zip in  <world>/datapacks/   then  /reload
TRIGGER   /trigger meteor          (any player, no cheats needed)
          /function meteor:summon  (admin)  |  meteor:auto_on / auto_off
OTHER     /function meteor:cleanup   remove a meteor mid-flight
          /function meteor:reset     rebuild the End island on the next meteor

SEQUENCE (20 ticks = 1 s)
  falling   glowing purple rock with magma core, fire trail, danger ring on the ground, thunder
  impact    shockwaves, 5 explosions, sonic boom, 18 amethyst shards fly out and rain down, screen shake
  +0.3 s    10 glowing fissures that branch
  +1.2 s    23 giant amethyst spires erupt (14-30 blocks tall, lit from inside)
  +5 s      crying-obsidian gate opens with a sky beam
PORTAL      leads to a floating amethyst island in the End at 500, 65, 500
            (return gate there takes you back to the latest crater)
WARNING     shockwave hurts within 8 blocks; the meteor also turns the weather to thunder
